Ecommerce Design Project:

This is a sample deign for the students to practice how to create a logo
and how to design e-commerce webpage.This assignment makes the
students easily understand how to create design and make concepts
according to the design element.

In order to create a logo and a webpage we need software to create designs:

  • Adobe Illustrator-to create logo design
  • Adobe Photoshop-to create webpage design

Before creating a design there are various stages a designer has to follow:

  • Understanding the Brief
  • Start research
  • Make strategy
  • Build development
  • Presentation
  • Launch

Learning Design:

Learning the software and implementing the design is very important.
Well researched design will produce an effective output with required look and feel.
Every design will be different according to the project needs.

The important thing is every design will not be the same and every designer's
output will be different based on the creativity and imagination. But the
implementation of the concepts and understanding the design brief plays a
vital role to produce the effective design output.

Let's try an Assignment:

In this assignment try creating a logo design and webpage design. The

this example and create your own logo design and web page design.
